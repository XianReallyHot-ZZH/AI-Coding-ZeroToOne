# PG-MCP 自然语言测试数据集

本测试数据集基于 fixtures 目录下的 SQL 文件生成，用于测试 pg-mcp 的自然语言到 SQL 转换功能。

## 测试数据库概览

1. **small_blog.sql** - 简单博客系统（5张表，1个视图，~60行数据）
2. **medium_ecommerce.sql** - 电商系统（18张表，4个视图，~800行数据）
3. **large_erp.sql** - 企业资源规划系统（40+张表，15+视图，多schema，5000+行数据）

---
